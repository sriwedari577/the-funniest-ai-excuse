A deterministic Node program that writes one original one-line excuse an AI agent gives after failing a task to `entry.txt`. It uses only the Node standard library and produces identical bytes on every run.

## Run

```sh
node main.ts
```

By default the program writes to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
